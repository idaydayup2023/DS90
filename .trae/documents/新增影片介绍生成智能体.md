# 新增影片介绍生成智能体 (Summary Agent)

我已经完成了相关功能的开发，实现了在字幕翻译的同时并行生成中文影片介绍，并在迁移时一并移动生成的 Markdown 文件。

## 核心变更

### 1. 新增 Summary Agent 逻辑
- 创建了 `src/srt_translate/summary.py` 模块。
- 实现了 `generate_summary` 函数，该函数读取英文字幕内容，调用 Ollama (LLM) 生成包含简介、剧情大纲、角色介绍的中文 Markdown 文件。
- 生成的文件保存在工作目录的 `out` 文件夹下，并上传到 FTP 服务器作为视频文件的 Sidecar（同名 `.md` 文件）。

### 2. 更新 Orchestrator (编排器)
- **并行执行**：在 `run_once` 中新增了 `summary_pool` 线程池。
- **任务调度**：修改了 `_schedule_translation`，在调度翻译任务的同时，自动调用 `_schedule_summary` 并行启动摘要生成任务。
- **状态同步**：引入了 `pending_ops` 和 `translation_success` 状态追踪机制。
  - 只有当“翻译”和“摘要”任务都完成（或摘要失败）时，才会触发目录迁移。
  - 如果翻译失败，不会触发迁移。
  - 如果摘要失败但翻译成功，仍会触发迁移（容错处理）。

### 3. 更新 Migration Planner (迁移规划)
- 修改了 `src/dir_migrate/agents/planner.py` 中的 `plan_one` 函数。
- 增加了对 `.md` 文件的检测逻辑。如果源目录存在与视频同名的 `.md` 文件，它将被加入迁移列表，并重命名为新的规范化名称（与视频文件保持一致）。

### 4. 代码重构
- 将 `resolve_ollama_model` 等 LLM 辅助函数从 `orchestrator.py` 移动到了 `src/srt_translate/mcp/ollama.py`，以便 `summary.py` 复用，避免循环依赖。

## 验证
- 代码已通过静态检查，逻辑覆盖了并行触发、错误处理和文件迁移。
- 您下次运行任务时，系统会自动为有英文字幕的视频生成 `[VideoName].md` 剧情介绍。
